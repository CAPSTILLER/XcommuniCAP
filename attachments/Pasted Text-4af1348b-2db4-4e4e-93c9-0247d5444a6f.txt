prompt for grok:

You are an expert front-end engineer. Build a complete, production-ready, single-file HTML/CSS/JavaScript web application called "XcommuniCAP". This is an emoji matrix text-art generator specifically designed for creating formatted emoji art posts on X (Twitter) and Farcaster.

1. Layout & Core Dimensions
• Standard Mode: 19 columns by 7 rows (133 emojis total). This grid ratio formats cleanly in the X feed timeline.
• Alt Vertical Mode: 19 columns by 52 rows (988 emojis total) for tall, vertical scrolling banner posts.
• Display: A responsive CSS grid where each cell is a square containing either the background emoji or foreground/letter emoji.

2. Typography & Bitmaps (5x5 Pixel Font Dictionary)
• Implement a 5x5 binary bitmap dictionary for all uppercase letters (A-Z), numbers (0-9), and punctuation (!, ?, $, space).
• 19x7 Mode Character Layout:
- Accepts 1 to 3 characters.
- 1 character: centered at column index 7 (spanning columns 7 to 11), row offset 1.
- 2 characters: positioned at column indices 3 and 11, row offset 1.
- 3 characters: positioned at column indices 1, 7, and 13, row offset 1.
• 19x52 Alt Vertical Mode Character Layout:
- Accepts 1 to 8 characters arranged vertically from top to bottom.
- Characters centered horizontally at column index 7.
- Each character is 5 rows high with a 1-row gap between letters, centered vertically on the 52-row canvas.

3. Interactive Controls & Modes
• Mode Switcher: Toggle between 19x7 Standard and 19x52 Alt Vertical format.
• Quick "CAP" Button: Instantly sets text to "CAP" and renders the signature cap pattern.
• Word Input & Set Button: Text input with live character cap (3 for normal mode, 8 for alt mode).
• Freehand Drawing Mode: When toggled on, clicking or dragging across cells toggles individual cell states between background and foreground.
• Invert Button: Inverts all cells on the matrix.
• Clear Button: Resets all cells to the background emoji.
• Swap Button: Swaps the current background and foreground emojis.

4. Emoji Selectors
• Two picker panels: Background Emoji and Letter/Foreground Emoji.
• Tabbed selection for each:
- Popular tab (11 staple emojis): blue square, white square, hotdog, hammer and pick, blue heart, white heart, razor, ogre, eyes, black square, b button.
- All Emojis tab: 123 curated unicode emojis.
• Custom Emoji Input: Text box allowing the user to paste any unicode emoji or symbol as background or foreground.

5. Export & Sharing
• Copy Art Button: Formats the entire grid as a multiline string (rows joined by newline characters) and copies it directly to the clipboard. Show a temporary toast notification on success.
• Post to X Button: Encodes the multiline text and opens https://twitter.com/intent/tweet?text=... in a new window.

6. Visual Styling & Theme
• Dark theme: #0A0A0A base background, #171717 card backgrounds, #BA0A0E red accents and glows.
• Clean typography, smooth transitions, mobile-responsive layout, and zero external dependencies.

Deliver the complete, working, self-contained index.html document with inline style and script tags.
